CSV File Format Instructions

Please ensure your CSV file follows these format requirements:

  1. File must be in CSV (Comma Separated Values) format
  2. File must contain the following columns (first row as headers):
student_id,username,email 123456,John Doe,johndoe@polyu.edu.hk 123457,Mary Smith,marysmith@polyu.edu.hk

Notes:

  • student_id: Student ID (must be an integer) used to match students in the database
  • username: Student name
  • email: Student email (must use polyu.edu.hk domain)
  • The system will check if the student exists in the database using student_id
  • If the student exists but is not registered for this course, they will be automatically added
