# Project Language Standards

## Overview
This project uses English as the primary language for all code, comments, and user interface text. Please adhere to these standards in all contributions.

## Guidelines

1. **Code Comments and Documentation**
   - All comments must be in English
   - Function, class, and variable names should be in English
   - Document string comments should be comprehensive and in English

2. **User Interface**
   - All labels, buttons, alerts, and messages must be in English
   - Form placeholders and input examples should be in English
   - Error messages and status notifications must be in English

3. **Template Files**
   - All HTML templates should use English text for all visible elements
   - JavaScript embedded in templates should use English for strings and comments
   - CSS comments should be in English

4. **Configuration and Settings**
   - Configuration comments should be in English
   - Environment variable descriptions should be in English

## Rationale
Using a consistent language throughout the project improves:
- Code readability and maintainability
- Onboarding of new team members
- Collaboration with international contributors
- Professional appearance of the application

Please ensure all new contributions follow these language standards.
